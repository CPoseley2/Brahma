# Drill card artwork

Add PNG artwork here using the drill ID as the filename, for example:

```text
gates-galore.png
castle-crashers.png
three-v-three.png
```

The build discovers matching files automatically. No JavaScript or manifest edit is required. The matching ID is shown on every card in the live Drill Cards view.

Keep cards in a consistent 4:3 landscape format when possible. Compress each file to less than 5 MB before committing and deploying.
